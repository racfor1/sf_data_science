# Программа анализа произвольного CSV-файла с табличными данными

## Описание
Программа реализовывает функционал анализа произвольного CSV-файла с использованием Streamlit.
<br>
Обладает следующим функционалом:
- загрузка CSV-файла для анализа;
- корректное преобразование полученных данных к типам данных pandas;
- отображение содержимого файла в виде таблицы;
- поля для выбора столбцов таблицы;
- статистический анализ выбранного пользователем столбца: среднее значение, медиана, среднеквадратичное отклонение;
- построение разных типов графиков для выбранных пользователем пар столбцов;
- отдельная кнопка для загрузки построенного графика;
- построение статистических графиков для выбранного пользователем столбца: 
- - график распределения в виде кривой и столбчатой диаграммы;
- - график взаимного распределения значений столбцов;
- используются состояния сеанса и кеширования.

pip install -r requirements.txt

## Запуск

|------|----------|

Создан удобный инструмент для анализа таблиц загружаемых из csv.
