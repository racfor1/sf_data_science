# Проект: Анализ резюме из HeadHunter

## Описание
Данный проект посвящён анализу данных о соискателях с использованием набора данных, содержащего информацию о резюме пользователей с платформы [HeadHunter](https://hh.ru). Цель исследования — компания HeadHunter хочет построить модель, которая бы автоматически определяла примерный уровень заработной платы, подходящей пользователю, исходя из информации, которую он указал о себе. 

## Структура файлов

| Файл | Описание |
|------|----------|
| `data\dst-3.0_16_1_hh_database.csv` | Исходный набор данных с резюме, доступен по [ссылке](https://disk.yandex.ru/d/QxeQseDcpgXxxA). |
| `data\ExchangeRates.csv` | Курсы валют для перевода ЗП в рубли |
| `\plotly\` | Каталог содержит html страницы с графиками. |
| `Project-1. Ноутбук-шаблон.ipynb` | Jupyter Notebook с выполненным анализом. [Открыть](/homework_modul_22_PJ_01/Project-1.%20Ноутбук-шаблон.ipynb) |
| `requirements.txt` | Версии модулей |
| `README.md` | Текущий файл с описанием проекта |
